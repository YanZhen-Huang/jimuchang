怎么用

  1. 左侧拖动积木到工作区，拼出演示流程
  2. 右侧舞台放元素（工具栏添加，拖动摆位置）
  3. 选中元素可在属性面板调外观、入场动画、关键帧
  4. 点右上角▶ 播放全屏放映（空格推进、Esc 退出）
  5. 保存为 .bdp 单文件；更多→导出放映包发给别人

快捷键

Ctrl+S / Ctrl+O / Ctrl+N保存 / 打开 / 新建
Ctrl+Z / Ctrl+Y撤销 / 重做（元素编辑）
Del删除选中元素
方向键（+Shift）微调位置 1px / 10px
F5播放
空格 / ← → / Esc放映时：推进 / 切场景 / 退出
