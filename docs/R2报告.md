# R2 报告：元素脚本区（UI 切换 + 自我版积木 + 元素事件执行）

> 2026-10-03 · 元素中心重构第二期
> 状态：**已完成**（R2TEST + 全回归通过）

## 本期目标（按重构方案 R2）

用户给任意元素写**独立脚本**（不再需要"选元素"下拉），播放时元素各自按自己的剧本表演、互不干扰。

## 实现摘要

### 1. 自我版积木（37 块，blocks.js）

- 命名规则 `jimu_self_ + 原名去掉 jimu_`（如 `jimu_self_el_show`），编译层自动归一化映射回原 IR 分支
- 覆盖：事件帽 4（当我开始/当点击我/当收到消息/当克隆体启动时）、运动 6、外观 10、动画 2、克隆 1（克隆自己）、媒体 4、感知 1（我的 x/y/…）、特效 1、3D 8
- 文案去除元素下拉（"让 [元素] 沿朝向移动" → "沿朝向移动"），样式分类与全局版一致
- 独立定义（不共享现有 init），零改动现有块 → 零回归风险

### 2. 编译层（IRCompiler）

- `compileWorkspace(workspace, { selfMode })`：元素脚本编译时全部元素引用解析为 `@self`（复用 v1 克隆体机制，执行时注入 `ctx.selfElId`）
- `EL(b)` 辅助：selfMode 下返回 `'@self'`，否则读 ELEMENT 字段（全 39 处替换）
- `compile`/`exprOf` 开头类型归一化（`jimu_self_xxx` → `jimu_xxx`）
- 自我版帽子映射：`onStart` / `onElementClick` / `onMessage`（广播，R3 通）/ `onCloneStart`

### 3. 执行器（executor.js）

- `compileAll` 增加元素脚本编译：`scripts.elements[elId]`
- 播放开始：每个母体元素执行自己的「当我开始」（self=自己；克隆体不执行）
- `trigger('onElementClick', id)`：追加该元素的「当点击我」脚本
- `triggerCloneStart(cloneId, templateElId)`：追加模板元素的「当克隆体启动」脚本（self=克隆体）

### 4. 编辑器 UI

- **脚本切换栏**（积木区顶部）：`[全局][🔷甲][🔷乙]…`——点击切换积木工作区（含工具箱切换：元素上下文用自我版工具箱）
- **元素列表条**（舞台下方）：元素 chips 点击=选中+切脚本+属性面板；右键菜单（编辑脚本/重命名/复制/锁定/置顶置底/删除）
- `JimuBlocks.switchTo('el:<id>')` 上下文支持；空脚本保存为 null
- `Editor.select` 自动通知两个栏刷新（notifyBars）

## 本期踩坑

1. **python 批量替换反噬**：全局替换 `b.getFieldValue('ELEMENT')` → `this.EL(b)` 时把 `EL` 方法体自己的实现也替换了 → `EL` 无限自递归（Maximum call stack size exceeded，39 块实例化时爆栈）。教训：批量替换后必须检查"被替换代码自身"是否命中。
2. **测试代码引用快照**：判定表达式在对象被后续操作修改后才求值（`a.y===300` 在点击 +50 后判定）→ 误报 FAIL。判定须在状态改变前算好。
3. **视觉误读**：截图低分辨率下 🔷 菱形图标看起来像 🅣（T 形）——放大 250% 后确认正常。排查 UI 问题先放大再下结论。
