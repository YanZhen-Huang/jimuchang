## 1. 项目概述

### 1.1 一句话定位

**积木剧场**是一款本地桌面工具：用拖拽图形化积木的方式，编排带 2D/3D 动画的演示（类似 PPT 的放映效果），一键全屏放映，可导出为浏览器直接打开的放映包。

### 1.2 目标用户与场景

- 学生课堂展示、项目路演、比赛答辩
- 教学演示、科技作品介绍
- 任何"想说清楚一件事"的演示场合

### 1.3 设计哲学

1. **积木即时间轴**：不做视频剪辑式的时间轴，演示流程由积木顺序决定；"等待动画播完"是默认语义。
2. **三层动画体系**：元素预设入场动画（简单）→ 积木命令动画（灵活）→ 关键帧动画（自由），按需选用。
3. **单文件项目**：`.bdp` 一个文件打包全部资源，换电脑、发微信不丢素材。
4. **完全离线**：不依赖网络、不依赖外部服务，资源全部内置。
5. **AI 可操控**：开放本地 API + MCP 服务器，AI（opencode 等）可直接生成、修改、检查演示。

### 1.4 命名约定

| 项 | 值 |
|---|---|
| 中文名 | 积木剧场 |
| 英文标识 | jimuchang |
| 项目目录 | `~/jimuchang` |
| 可执行文件 | `~/.local/bin/jimuchang` |
| 桌面快捷方式 | 积木剧场（`~/.local/share/applications/` + `~/Desktop/`） |
| 图标 | `~/.local/share/icons/hicolor/scalable/apps/jimuchang.svg` |
| 项目文件扩展名 | `.bdp` |
| 版本 | 0.1.0 |

### 3.2 技术栈与版本

| 组件 | 版本/选择 | 说明 |
|---|---|---|
| Qt | 6.8.0（系统已装） | Widgets + WebEngineWidgets + WebChannel + Network |
| C++ 标准 | C++17 | 与用户现有项目一致 |
| 构建 | CMake 3.31 + GCC 12 | 系统已装 |
| WebEngine | libqt6webenginewidgets6 6.8.0 | 系统已装，需注意沙盒/GPU 参数 |
| Blockly | 13.3（npm，UMD 单文件） | 已验证（P0）：blockly.min.js + msg/zh-hans.js 全局加载，zelos 渲染器 |

| ECharts | 6.1（npm） | 图表 |

| Node.js | v24（仅开发期） | 拉取前端依赖，运行时不依赖 |

### 3.3 资源打包

- 全部前端文件（html/css/js/vendor/示例模型）放入 `web/`，通过 Qt 资源系统 `web.qrc` 编译进二进制。
- 交付形态：单文件可执行（预计 10~20 MB，WebEngine 本体是系统库不占体积）。
- 网页入口：`QWebEngineView::setUrl("qrc:///index.html")`。
- .bdp 的 zip 打包/解包使用 JSZip 在网页侧完成；C++ 只做"字节流 ↔ 文件"的搬运（Base64 经 QWebChannel 传输）。

### 3.4 开发与调试

- 构建：`cmake -B build && cmake --build build -j`
- 运行：`./build/jimuchang`
- 网页调试：环境变量 `QTWEBENGINE_REMOTE_DEBUGGING=9222`，用 Edge 打开 `http://127.0.0.1:9222` 调 devtools
- WebEngine 兼容参数（P0 实测确定，候选）：`--no-sandbox`、`--disable-gpu`、`--use-gl=angle`、`QTWEBENGINE_CHROMIUM_FLAGS`
- 前端依赖更新：`npm install blockly three echarts jszip --registry=https://registry.npmmirror.com`，将 dist 文件拷入 `web/vendor/`

### 3.5 性能指标

| 项 | 目标 |
|---|---|
| 界面操作响应 | < 100ms，交互流畅 60fps |
| 演示播放 | 60fps（2D 元素 < 50 个/场景） |
| 启动时间 | < 3 秒（冷启动含 WebEngine） |
| 内存占用 | 常态 300~600 MB（WebEngine 特性，可接受） |
| 单场景元素上限 | 建议 50 个（超量提醒） |
| 3D 模型面数 | 建议 < 10 万面 |

### 4.2 项目数据模型（.bdp）

#### 4.2.1 容器格式

`.bdp` 是一个 ZIP 文件：

```
project.bdp (zip)
├── project.json        # 主数据（见下）
├── meta.json           # {"app":"jimuchang","appVersion":"0.1.0","created":"...","modified":"..."}
└── resources/          # 导入的资源，文件名 = <8位哈希>_<原文件名>
```

#### 4.2.2 project.json 完整结构

```jsonc
{
  "format": "jimuchang-project",
  "version": 1,
  "name": "我的演示",
  "canvas": { "width": 1920, "height": 1080 },
  "theme": { "bg": "#0F1115" },
  "resources": [
    { "id": "res_1", "name": "photo.png", "path": "resources/a1b2c3d4_photo.png",
      "type": "image", "size": 123456 }
  ],
  "scenes": [
    {
      "id": "scene_1",
      "name": "封面",
      "background": { "type": "color", "value": "#0F1115" },
      // type: color | gradient | image
      // gradient: {"type":"gradient","value":{"kind":"linear","angle":135,"stops":[["#111","0"],["#333","1"]]}}
      // image:    {"type":"image","value":{"resourceId":"res_2","fit":"cover"}}
      "transition": { "type": "fade", "duration": 0.6 },
      // type: none | fade | slide-left | slide-right | slide-up | slide-down | zoom
      "elements": [ /* 见 4.2.3 */ ],
      "blocks": { /* Blockly 序列化：workspace JSON，见 4.4.3 */ }
    }
  ],
  "globalBlocks": { /* 同上：全局脚本工作区 */ },
  "music": { "resourceId": null, "loop": true, "volume": 0.8 }  // 全局背景音乐
}
```

| 强调 | pulse, shake, wobble, breathe, glowPulse, neon, sweep, glitch |
| 缓动（12 条） | linear, easeInQuad, easeOutQuad, easeInOutQuad, easeInCubic, easeOutCubic, easeInOutCubic, easeInBack, easeOutBack, easeInOutBack, easeOutElastic, easeOutBounce |

### 4.3 舞台引擎

#### 4.3.1 渲染结构（DOM）

```html
<div id="stage">                      <!-- 逻辑 1920×1080，transform:scale 适配 -->
  <div class="layer layer-bg"></div>      <!-- 背景：色/渐变/图 -->
  <div class="layer layer-3d"></div>      <!-- Three.js canvas（3D 场景） -->
  <div class="layer layer-elements"></div><!-- 2D 元素（绝对定位 div/img/video/canvas/iframe） -->
  <div class="layer layer-effects"></div> <!-- 粒子/特效 canvas -->
  <div class="layer layer-ui"></div>      <!-- 进度点/点击提示（仅演示模式） -->
</div>
```

- 坐标换算：逻辑坐标 × 缩放系数 = 屏幕坐标；窗口任意尺寸下保持 16:9 letterbox。
- 元素渲染：统一 `transform: translate3d + rotate + scale`，走 GPU 合成层。
- 视频/图表/3D/小程序各自独立渲染（video 标签 / ECharts canvas / Three.js canvas / iframe）。

#### 4.3.2 动画引擎

- 常规动画走 **Web Animations API (WAAPI)**：`element.animate(keyframes, options)`，`options.easing` 接缓动模块提供的 cubic-bezier。
- 关键帧动画走 **rAF 插值**：每帧读取各轨道插值结果写入 style（统一批量更新，避免布局抖动）。
- 时序控制：一切动画返回 Promise；`等待动画完成` 是默认语义；`并行` 由积木的"同时执行"语法糖实现（默认顺序执行）。
- 缓动模块 `easing.js`：注册表结构 `{ name: fn(t) }`，内置 12 条；外部可注册新函数（未来曲线编辑器接口）。

#### 4.3.3 转场

- 实现：旧场景截屏（canvas 或直接克隆 DOM）+ 新场景叠加，跑过渡动画，结束后清理。
- 类型：none / fade / slide-* / zoom（P1），擦除等 P6。

#### 4.4.3 IR 与执行引擎

- 自定义积木**不生成 JS 代码**，而是编译为 **IR 指令数组**（可序列化、可静态分析、便于导出与调试）。
- 表达式（数字/文本/布尔）编译为可求值子树（字面量/变量读取/运算/属性读取）。
- IR 示例：

```jsonc
[
  { "op": "scene.go", "scene": "scene_1" },
  { "op": "el.anim", "el": "el_1", "anim": "fadeIn",
    "duration": 0.6, "delay": 0, "easing": "easeOutCubic" },
  { "op": "wait", "sec": { "expr": "num", "value": 1 } },
  { "op": "ctrl.repeat", "times": { "expr": "num", "value": 3 }, "body": [ ... ] },
  { "op": "ctrl.if", "cond": { "expr": "cmp", "op": ">", "left": {...}, "right": {...} },
    "then": [ ... ], "else": [ ... ] },
  { "op": "var.set", "name": "计数", "value": { ... } },
  { "op": "func.call", "name": "出场三连", "args": [] },
  { "op": "js.eval", "code": "await jimu.wait(1); jimu.sfx('ding')" }
]
```

- 执行引擎（`executor.js`）：
  - 单条脚本 = 异步解释器，返回 Promise；支持 暂停（await 一个 resumed Promise）/ 停止（AbortSignal 检查点）。
  - 多个事件（如点击元素 x2、按键）各自启动独立执行上下文，互不阻塞。
  - 运行中积木高亮（blockly 的 highlight API），便于教学与调试。
  - 代码块用 `AsyncFunction('jimu', code)` 执行，错误捕获后舞台角落显示提示条。

### 4.5 关键帧引擎（P3）

- **轨道面板**：底部抽屉，选中元素后展开；时间刻度 0~N 秒；5 条轨道（X/Y/缩放/旋转/透明度）。
- **交互**：点"＋"在当前时间打点；拖动关键帧点改时间/数值；右键删除；点选段落下拉选缓动；播放头拖拽预览；▶ 试播；循环开关；清空轨道。
- **数据**：见 4.2.3 `keyframes`；插值器按属性归一化（x/y 绝对像素、scale 无量纲、rotation 度、opacity 0~1）。
- **运行时**：rAF 循环写 style；支持多元素并行；由积木 `el.keyframes` 启动/停止；可循环。
- **缓动模块化**：`easing.register(name, fn)`，预设 12 条从同一注册表读取；未来曲线编辑器只需向注册表加贝塞尔函数。

### 4.7 媒体子系统

- **音频**：HTMLAudio 通道管理（music 通道 1 个 + sfx 池 8 个）；跨场景连播；音量/淡入淡出用 rAF 渐变。
- **视频**：`<video>` 元素；格式以 P0 实测为准（目标 mp4/H.264 + webm 双保险）。
- **帧素材**：GIF 直接 `<img>`；序列图/雪碧图用 canvas 自绘 + rAF 控帧（播放/暂停/速度）。

### 4.8 3D 子系统（P4）

- 每场景可选 3D 层（背景）：WebGLRenderer（antialias，pixelRatio ≤ 2）。
- 模型：GLTFLoader 加载 glb/gltf；内置示例模型存 `web/assets/models/`（RobotExpressive 带骨骼动画、DamagedHelmet）。
- 相机积木实现：Tween（自研 lerp 补间）驱动 camera.position/target；环绕 = 球坐标动画。
- 灯光预设：预设参数表（ambient/directional/point 组合）。
- 模型动画：AnimationMixer；积木控制播放/暂停/循环/速度。
- 与 2D 共存：canvas 在下层，2D 元素层透明叠加；性能不足时建议减少同时元素。

### 4.10 AI 接口（P5）

#### 4.10.1 本地 HTTP API

### 4.11 导出放映包（P6）

- 产物：文件夹（可再打包为 zip）

```
我的演示-放映包/
├── index.html          # 引擎 + 内联项目数据（<script>window.__PROJECT__=...</script>）
├── assets/             # 引擎 JS/CSS（player 精简版）
└── media/              # 图片/音频/视频（相对路径引用）
```

- file:// 兼容策略（关键）：
  - 项目 JSON 内联（避免 fetch 被 CORS 拦）
  - 图片/音频/视频：用标签相对路径（img/video/audio 的 src 在 file:// 下不受 CORS 限制）
  - 3D 模型：base64 内联后 `GLTFLoader.parse(ArrayBuffer)`（绕开 fetch）
  - 网页小程序：相对路径 iframe（file:// 可用）；若小程序内部 fetch 本地文件会被拦，文档提示"复杂小程序建议用 HTTP 放映"
  - 播放引擎与 Blockly 无关：导出播放器 = IR 解释器 + 舞台引擎（体积小）
- 交互照常：点击/按键事件、变量、函数全部走 IR 解释器。
- 附加：`说明.txt`（怎么放、怎么用）。

## 7. 风险与对策

| 风险 | 概率 | 对策 |
|---|---|---|
| WebEngine 在 Deepin/X11/NVIDIA 下启动异常（沙盒/GPU） | 中 | P0 首日实测；备选参数 --no-sandbox / --disable-gpu / --use-gl=angle；最坏情况用软件渲染（性能仍可接受） |
| Blockly 13 ESM 构建在 qrc 下加载失败 | 中 | P0 实测 import maps / 相对路径模块；失败则降级 Blockly 11 经典构建（功能不受影响） |
| mp4 视频不支持（WebEngine 编解码器缺失） | 低 | P0 实测；备选引导用户用 webm 转换（提供 ffmpeg 一行命令） |
| QHttpServer 开发包未装 | 低 | 补装 qt6-httpserver-dev；失败用 QTcpServer 手写 |
| 截图 grab() 在 WebEngine 下黑屏 | 中 | 三方案择优（grab / printToPdf / devtools） |
| 关键帧编辑器 UI 复杂度失控 | 中 | 严格按 4.5 范围（5 属性、无曲线编辑器）；先基础版上线再迭代 |
| 3D 性能不足 | 低 | 像素比限制、面数建议、加载提示；必要时降帧 |
| 项目周期长、费用累积 | — | 分期验收，随时可停；每期独立可用 |
| 示例模型版权 | 低 | 只用 Three.js 官方示例模型（CC 授权，随包注明来源） |
