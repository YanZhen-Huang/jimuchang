### 2. 带参函数（commit 74d27b7）

- **积木**（新"带参函数"分类）：`定义函数 [名] 参数 [x,y]`（帽） / `调用函数 [名] 参数①②③` / `函数参数 [名]`（表达式）
- **执行**：`ctx.args` 作用域链——调用时按函数定义绑定参数名，`finally` 恢复外层（**递归/嵌套调用正确**）
- **踩坑修复**：
  1. `parseParams` 定义在 IIFE 内、IRCompiler 在 IIFE 外 → ReferenceError（移到 IRCompiler 方法）
  2. compileAll 合并 funcs 时**丢 params 字段** → 参数绑定为 null → argv 恒 0（补上，FN 测试暴露）
  3. 动态下拉（函数名）在序列化加载时"选项未生成"→ 字段值被重置为空 → 弃用下拉改文本框
- **验证**：FN 端到端——定义 `走两步(n)`（self_change x += 函数参数 n）→ 调用 `走两步(100)` → 播放后 x 200→300 精确命中
