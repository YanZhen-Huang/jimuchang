# 品牌设计：logo 与海报

## 一句话

**一束聚光灯，打在一块积木上。** —— 剧场的仪式感，落在最朴素的搭建单元上。

## 设计理念（Stagecraft Minimalism · 舞台工坊极简）

这组视觉只相信两件事：**光**与**单元**。光负责郑重其事——不是霓虹的喧哗，而是一束角度收敛、安静的聚光灯；单元负责诚实——一块带两个凸点的积木，不多不少，是可被任何年龄的人拿起来、拼上去的东西。两者相遇，事物的身份就确定了：一个让每个人都能搭出舞台的工具。

颜色克制到近乎吝啬：纸白打底、炭黑成形、深金点睛。金色只出现在"光"上——logo 的光柱、标题句末的方点、一条 64px 的横线。它从不铺开，只做标点，像稿纸上最后落下的那一点墨。

空间上遵循工程图纸的纪律：左对齐、七十二像素的底板格网、贯穿的细分割线。整张海报被当作**一块积木底板**来排布——网格交点上的小凸点不是装饰，是坐标；信息不是被"展示"，而是被"安置"。每个元素都精确落在它该在的位置，如同零件落入卡槽。

排版是唯一允许"说话"的建筑材料：黑体承担重量，等宽字体承担出处——版本号、文件路径、工程注记一律用等宽，像机器铭牌上冲压出来的字。字号跳跃被刻意拉大：九十六像素的主张，十一像素的脚注，中间不留暧昧的过渡。

这套语言拒绝一切"聪明"的装饰：没有渐变，没有发光，没有 emoji，没有圆润的卡片堆。质感来自比例、对齐与留白——来自一个工匠反复用尺子量过三遍的自信。看上去朴素，做起来昂贵：这正是它要证明的事。

## Logo

- **构成**：45° 收敛的光柱（深金，低透明）＋ 一块双凸点积木（炭黑）
- **含义**：光 = 剧场与"被看见"；积木 = 搭建与上手；两个凸点 = 可组合的单元，也是品牌的最小记号
- **规范**：最小使用尺寸 24px；浅底用正版（`jimuchang-logo.svg`），深底用反白版（`jimuchang-logo-dark.svg`）；四周留白不少于图形高度的 1/4
- **PNG**：`jimuchang-logo.png` / `jimuchang-logo-dark.png`（512×512，透明底）

|---|---|
| 纸面底色 | `#F4F2ED` |
| 主形（文字 / 积木） | `#1C1F26` |

| 正文次级灰 | `#6B7280` |
| 注记浅灰 | `#8A8F98` / `#9AA0A8` |

## 字体

- 中文与标题：**Noto Sans CJK SC**（思源黑体）
- 注记与编号：**Noto Sans Mono CJK SC**（思源等宽）——用在版本号、仓库地址、工程标注

## 海报

- 尺寸 1080×1920（导出 @2x = 2160×3840），适合手机传播与打印
- 结构：品牌区 → 主张（"把演示做成能上手玩的"）→ 真实运行画面（窗口卡 + 冲印照片式副图）→ 规格表（2×2，凸点记号起行）→ 二维码与仓库地址
