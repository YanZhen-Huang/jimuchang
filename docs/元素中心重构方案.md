# 元素中心重构方案（v2）

> 日期：2026-09-25
> 状态：**方向定稿，待实施（R1-R4）**
> 关系：本文档是 v2 架构的"专用计划书"，与 `技术文档.md`（v1 架构）冲突处以本文档为准

---

## 1. 重构动因（初衷修正）

### 1.1 v1 的问题（做偏的地方）

| 问题 | 表现 |
|---|---|
| **场景是第一公民** | 内容被切成一页页；`切场景` = 整页重建——元素状态全丢、"翻页感"、"切换卡顿"的根源 |
| **元素只是素材** | 脚本按场景组织；要操作某个元素必须在下拉里按名字找；元素之间无法通信 |
| **缺少"元素自身行为"** | 元素没有自己的剧本（不能"当点击我→做X"），只能是场景流程的被动对象 |
| **结构绝对化** | 作者被迫用"场景"来组织一切内容，而不是用元素和脚本自由编排 |

### 1.2 v2 目标（回到初衷）

> **核心价值 = 积木化编程驱动连续、丝滑的动画演出。**
> 元素是演员（有剧本、有状态、跨章节延续）；舞台是连续的（一切变化都是"过渡"而非"重建"）；
> 章节只是给作者**理清思路**的书签，**不参与渲染与逻辑构建**。

| 原则 | 落地 |
|---|---|
| 元素是第一公民 | 全局元素列表；每个元素有自己的脚本区；自我版积木 |
| 切换丝滑 | 消灭"切换重建"；章节跳转 = 背景平滑过渡 + 显隐过渡 + 脚本通知 |
| 场景降级为辅助 | 章节 = 书签（背景 + 显隐预设）；作者可完全不用章节 |
| 基础能力不变 | 运动 / 动画 / 克隆体 / 关键帧 / 特效 / 3D / 媒体 全部保留，成为元素脚本的主力 |

## 2. 架构总览

```
┌─ 项目 ──────────────────────────────────────────────────────────┐
│                                                                  │
│  舞台（唯一、连续）                                                │
│  ├── 背景（纯色/渐变/图片，可被脚本平滑切换）                        │
│  └── 元素们（第一公民，一次渲染、永不因"切换"重建）                   │
│      ├── 外观/位置/动画/关键帧/特效/3D…（v1 全部能力）              │
│      └── blocks：自己的脚本                                        │
│          └── 事件：当开始（自己）/ 当点击我 / 当收到消息 / 当克隆体启动 │
│                                                                  │
│  章节（书签，辅助）                                                │
│  ├── name                                                         │
│  ├── preset：背景 + 元素显隐（跳转到此章节时应用）                   │
│  └── blocks：章节脚本（跳到本章节时执行）                           │
│                                                                  │
│  全局脚本（系统级事件：当演示开始 / 当按下键 / 当收到消息）           │
│                                                                  │
│  广播（元素之间/全局的通信）：广播 [消息] + 当收到 [消息]            │
└──────────────────────────────────────────────────────────────────┘
```

**"切换"的新语义**：跳到章节 = 背景交叉淡入 + 显隐过渡（元素 DOM 不重建、状态不丢）+ 执行章节脚本。

## 3. 数据模型 v2（完整 Schema）

```jsonc
{
  "format": "jimuchang-project",
  "version": 2,
  "name": "我的演示",
  "canvas": { "width": 1920, "height": 1080 },
  "theme": { "bg": "#0F1115" },

  // 唯一舞台（连续）
  "stage": {
    "background": { "type": "color", "value": "#0F1115" }
    // 背景类型同 v1：color / gradient / image
  },

  "resources": [ /* 同 v1：id/name/mime/path/type/size（+运行时 data） */ ],

  // 全局元素列表（第一公民）
  "elements": [
    {
      "id": "el_1", "type": "text", "name": "标题",
      "x": 100, "y": 200, "w": 800, "h": 120,
      "rotation": 0, "opacity": 1, "z": 1,
      "locked": false, "visible": true,
      "props": { /* 同 v1（按类型） */ },
      "entrance": null, "exit": null, "effects": [], "keyframes": null,
      "blocks": { /* Blockly 序列化：该元素的脚本 */ }
      // blocks 为 null 表示没有元素脚本
    }
  ],

  // 章节 = 书签（辅助；可为空数组，表示纯连续舞台）
  "chapters": [
    {
      "id": "ch_1", "name": "封面",
      "preset": {
        "background": { "type": "color", "value": "#0F1115" },
        "visibility": { "el_1": true, "el_2": false }
        // 跳转到本章节时：对列出的元素设置显隐；未列出的元素保持不变
      },
      "blocks": { /* Blockly 序列化：跳到本章节时执行 */ }
    }
  ],

  "globalBlocks": { /* 同 v1 */ },
  "music": { "resourceId": null, "loop": true, "volume": 0.8 }
}
```

**与 v1 的字段对照**

| v1 | v2 |
|---|---|
| `scenes[].name` | `chapters[].name` |
| `scenes[].background` | `stage.background`（当前）+ `chapters[].preset.background`（书签快照） |
| `scenes[].elements` | `elements`（全局合并，id 不变） |
| `scenes[].blocks` | `chapters[].blocks` |
| `scenes[].transition` | 章节跳转过渡（默认淡入淡出 0.6s，见 4.5） |
| `globalBlocks` | 不变 |

## 4. 运行时设计

### 4.1 连续舞台

- **渲染**：项目加载 → 按 z 一次性渲染全部元素；此后 DOM **不因章节跳转重建**（单元素属性变化走局部更新）
- **编辑模式**：显示全部元素（含显隐）；点书签 = 应用该书签预设（预览状态）
- **播放起点**：应用 `chapters[0].preset`（无章节则用舞台初始状态）→ 触发"当开始"事件
- **章节跳转**：背景过渡 + 显隐应用 + 章节脚本

### 4.2 事件系统（v2）

| 事件 | 定义在哪 | 触发与执行 | self |
|---|---|---|---|
| 当开始 | 元素脚本 | 演示开始时，每个**母体元素**执行一次 | 该元素 |
| 当开始 | 全局脚本 | 演示开始时 | — |
| 当点击我 | 元素脚本 | 点击该元素时；可多元素各自响应 | 该元素 |
| 当收到消息 | 全局 + 元素 | `广播`时，所有匹配脚本执行 | 元素脚本=该元素 |
| 当按下键 | 全局 | 按键时（演示模式） | — |
| 当克隆体启动 | 全局 + 元素 | 克隆体诞生时（self=克隆体） | 克隆体 |
| 当进入章节 | 章节脚本 | 跳转到该章节时 | — |

- 「当开始」与克隆体：母体在演示开始时执行「当开始」；克隆体只执行「当克隆体启动」（Scratch 语义）
- 点击命中：舞台 click → 找到目标元素 → 执行其「当点击我」脚本（多个脚本全部执行）

### 4.3 自我版积木（元素脚本）

- 元素脚本区展示的积木**不带元素下拉**，天然作用于"自己"
- 编译：`elId = '@self'`；执行时 `ctx.selfElId` 注入当前元素
- **复用 v1 已有的 `@self` 解析机制**（`exec` 入口统一替换）——引擎零改动
- 详细清单见 §5.2

### 4.4 广播系统

- `广播 [消息名]`：语句积木，任何脚本可用
- 触发：所有「当收到 [消息名]」脚本执行（全局脚本 + **全部元素的脚本**；元素脚本的 self=该元素）
- 消息名：文本（大小写敏感）；暂不做"广播并等待"

### 4.5 章节跳转与过渡

- `跳到章节 [名]`：
  1. 背景**交叉淡入**（旧背景 → 新背景，默认 0.6s）
  2. 显隐应用（preset.visibility：过渡可选淡入淡出，默认瞬时）
  3. 执行章节脚本
- 保留积木：`下一章节` / `重播本章节` / `从头开始播放`
- 过渡时长：`设置转场时长 N 秒`（v1 `设置转场` 的兼容形态）

### 4.6 播放与停止

- 播放：进入全屏 → 应用章节[0]预设 → 「当开始」事件 → 演示进行
- 停止：恢复编辑状态（快照隔离机制不变——播放改动不污染项目数据）
- 克隆体：随播放结束清理；章节跳转不清理（克隆体跨章节存活，除非背脚本删除）

## 5. 积木体系 v2

### 5.1 公共积木（全局/章节脚本）

保留 v1 全套（含元素下拉的版本、场景→章节改名的块），迁移映射见 §7.1。

### 5.2 自我版积木清单（元素脚本专用）

| 分类 | 积木文案 | IR（elId 固定 @self） |
|---|---|---|
| 运动 | 移动 [N] 步 | el.steps |
| 运动 | 在 [N] 秒内滑行到 x:[X] y:[Y]（缓动 [E]） | el.glide |
| 运动 | 面向 [N] 度 | el.face |
| 运动 | 将 [属性] 增加 [N] | el.change |
| 运动 | 移到 x:[X] y:[Y]（瞬移） | el.move |
| 外观 | 显示 / 隐藏 | el.show / el.hide |
| 外观 | 说 [文本] / 说 [文本] 持续 [N] 秒 / 停止说话 | el.say / el.say.stop |
| 外观 | 设为 [属性] = [值]（万能） | el.set |
| 外观 | 颜色设为 [色] | el.color |
| 动画 | 播放动画 [类型]（时长/延迟/缓动） | el.anim |
| 动画 | 播放关键帧动画（循环 [B]） | el.keyframes |
| 克隆 | 克隆自己 | el.clone.start |
| 克隆 | 删除本克隆体 | el.remove（@self） |
| 媒体 | 播放音效 | media.sfx |
| 检测 | 我的 [x/y/宽/高/旋转/透明度] | prop（@self 读取） |
| 检测 | 计时器 | timer |
| 事件 | 当开始 / 当点击我 / 当收到消息 / 当克隆体启动 | hat（元素域） |

- 逻辑/变量/函数/数学/文本：沿用 Blockly 内置（通用）
- 总计：**17 块自我版积木 + 4 个元素事件帽**

### 5.3 全局新增积木

- `广播 [消息]`（放"高级"或新增"通信"分类）
- `当收到 [消息]` 升级为双域（全局可用，元素脚本可用——元素版见自我版）

## 6. 编辑器 UI 设计

### 6.1 布局（v2）

```
┌─────────────────────────────────────────────────────────────┐
│ 工具栏（不变）                                                │
├───────────────────────────┬─────────────────────────────────┤
│                           │ 章节书签栏：[封面][特性][结尾][+]  │
│   积木工作区               ├─────────────────────────────────┤
│   顶部切换：                │                                 │
│   [全局 | 元素▾]           │         连续舞台                 │
│                           │   （全部元素同框；点书签=预览）    │
│                           ├─────────────────────────────────┤
│                           │ 元素列表：[🅣标题][🖼图][★…]      │
│                           ├─────────────────────────────────┤
│                           │ 属性面板（元素 / 舞台）            │
└───────────────────────────┴─────────────────────────────────┘
```

- **章节书签栏**（原场景标签栏改造）：chip 点击 = 预览该书签预设；右键 = 重命名 / 编辑章节脚本 / 删除；`＋` 新建（记录当前舞台状态为预设）
- **元素列表条**：横向滚动；点选 = 选中元素 + 积木区切到该元素脚本；右键 = 重命名/复制/删除/上移下移/锁定；工具栏"＋"添加的元素自动出现在列表
- **积木区切换**：下拉 `[全局脚本 | 元素：标题 | 元素：图片 | …]`（也可用选项面板"编辑该元素脚本"跳转）
- **属性面板**：选中元素 = 元素属性（v1 不变）；未选 = **舞台属性**（背景、音乐）+ 当前预览章节的预设设置

### 6.2 视觉与手感

- 章节书签栏与元素列表条均沿用现有 chip 风格
- 舞台不再有"翻页"视觉——书签预览时背景/显隐平滑过渡（200ms 编辑态过渡）

## 7. 迁移（v1 → v2）

### 7.1 转换规则

| v1 | v2 转换 |
|---|---|
| `scenes[]` | `chapters[]`（顺序保留） |
| `scene.name` | `chapter.name` |
| `scene.background` | `chapter.preset.background`；**第一章的背景同时写入 `stage.background`** |
| `scene.elements`（各场景合并） | 全局 `elements`（id 不变；重名不改） |
| 元素在各场景的 `visible` | `chapter.preset.visibility[elId]` = 该场景中的 visible 值；未出现在该场景的元素 → false |
| `scene.blocks` | `chapter.blocks` |
| `scene.transition.duration` | 章节跳转过渡时长（取第一章的） |
| `globalBlocks` | 不变 |
| 元素 `blocks` 缺失 | 补 null |

- 迁移时机：**打开 version 1 项目时自动转换**（内存）；保存时写为 version 2
- 播放行为兼容：播放开始 = 跳到章节[0]（预设应用）→ 与旧"从第一场景开始"感知一致

### 7.2 旧积木兼容映射

| v1 积木 | v2 行为 |
|---|---|
| 切换到场景 X | = 跳到章节 X（语义升级，选中值沿用） |
| 下一场景 | 下一章节 |
| 重播当前场景 | 重播当前章节（应用预设） |
| 从头开始播放 | 跳到第一章（无章节则从头） |
| 设置转场（类型/时长） | 只保留时长（过渡统一为平滑淡入淡出+位移可选） |
| 当进入场景 X | 当进入章节 X（章节脚本域） |
| 把背景色设为 | 直接改舞台背景（可平滑） |

> 旧积木类型名不变（Blockly 序列化兼容），仅在执行语义上映射——**旧项目脚本无需改动**。

| 层 | 状态 |

## 9. 分期计划（每期验收）

| 期 | 内容 | 验收标准 |
|---|---|---|
| **R1** | Project v2 + 迁移器 + Stage 连续化 + 章节书签运行时 | ① 旧 demo 打开自动迁移、元素全在舞台；② 跳章节 = 平滑换背景+显隐；③ 播放连续不重建 |

| **R3** | 广播系统 + 章节跳转过渡打磨 + UI 细节（元素列表右键/章节右键） | 元素间消息通信示例跑通；章节切换无感丝滑 |

- 每期结束：更新技术文档 / P 报告 / 记忆库 / 安装版 / GitHub 推送

## 10. 风险与对策

| 风险 | 对策 |
|---|---|
| 重构面大、回归多 | 分期推进；每期全量回归清单；v1 代码不删（迁移层隔离） |
| 元素脚本 vs 公共脚本两套积木 | 工具箱按上下文切换积木集（同一分类渲染不同块）；IR 层统一 |
| 元素过多时编辑性能 | 一次性渲染 + 局部更新；元素列表虚拟化（如需要） |
| 用户习惯切换（场景→章节书签） | 书签栏视觉上与旧标签栏接近；旧项目迁移后观感一致 |
| 播放器导出兼容 | 导出使用 v2 运行时（共享源文件）；旧导出包独立不受影响 |
| 广播误触发（同名消息） | 消息名精确匹配；文档说明命名建议 |

## 11. 重构完成的定义（验收总标准）

- [ ] 舞台连续：章节跳转不重建元素 DOM，状态延续
- [ ] 元素第一公民：每个元素可拥有独立脚本，元素事件（当开始/点击我/收到消息/克隆体）可用
- [ ] 自我版积木完整（§5.2 清单），元素脚本里不出现"选元素"
- [ ] 广播系统可用（元素间通信）
- [ ] 章节书签：预设（背景+显隐）+ 跳转 + 章节脚本
- [ ] 旧项目无损迁移（v1 打开→保存→再打开 一致）
- [ ] 全部 v1 能力回归通过（运动/动画/关键帧/特效/3D/克隆/媒体/图表/PPT/放映包/AI）
- [ ] 文档（技术文档/使用文档）与示例同步为 v2
