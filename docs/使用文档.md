# 积木剧场 · 使用文档

> 版本 0.1.0 · 2026-09-23
> 一句话：拖积木，编排你的演示。

## 1. 三分钟上手

1. **打开程序**：桌面双击「积木剧场」或应用菜单搜索
2. **玩示例**：点工具栏「示例」→ 点右上角「▶ 播放」→ 空格推进、Esc 退出
3. **自己做一个**：
   - 左侧「积木面板」拖出积木到工作区，拼出流程
   - 右侧舞台用「＋文字 / ＋图片 / …」添加元素，拖动摆位置
   - 选中元素 → 下方「属性面板」调外观、入场动画、关键帧
   - 「保存」存成 `.bdp` 单文件（含所有素材）
4. **分享**：「＋更多 ▾ → 导出放映包」生成一个 HTML 文件，发给别人双击就能看

## 2. 界面速览

```
┌─────────────────────────────────────────────────────────────┐
│ 工具栏：新建 打开 保存 ↶↷ ｜ ＋文字 图片 视频 音频 更多▾ ｜ ？示例 ▶播放 │
├──────────────────────────┬──────────────────────────────────┤
│                          │ 场景标签：[全局][封面][特性][+]    │
│   积木工作区              │ ┌──────────────────────────────┐ │
│   （左：积木分类面板）      │ │        舞台预览              │ │
│                          │ └──────────────────────────────┘ │
│                          │ 属性面板（选中元素时）             │
├──────────────────────────┴──────────────────────────────────┤
│ 关键帧轨道编辑器（点属性面板「关键帧动画…」弹出）              │
└─────────────────────────────────────────────────────────────┘
```

- **场景标签**：切场景 = 同时切舞台预览和该场景的积木脚本；「全局」放跨场景脚本
- **工作区切换**：橙色帽子积木（当…）是每条脚本的开头；没有帽子开头的积木不会执行（播放时会提醒）

## 3. 元素

| 元素 | 添加方式 | 特色 |
|---|---|---|
| 文字 | ＋文字 | 双击直接改字；字体字号颜色对齐 |
| 图片 | ＋图片 | 支持 png/jpg/gif/webp（GIF 直接会动）|
| 视频 | ＋视频 | mp4/webm；可循环/静音/自动播放 |
| 音频 | ＋音频 | 放映时不显示，仅发声；可进场景自动播放 |
| 形状 | ＋更多 | 矩形/圆/椭圆/三角/箭头/直线 |
| 图标 | ＋更多 | 直接粘贴 emoji 😀🚀⭐ |
| 图表 | ＋更多 | 柱状/折线/饼/环形；属性面板填数据（逗号分隔）|
| 帧动画 | ＋更多 | 雪碧图切帧或序列图；积木控播放/速度 |
| 3D 模型 | ＋更多 | 内置机器人（骨骼动画）；也可导入 .glb |
| 小程序 | ＋更多 | 嵌入一个 HTML 页面，与积木互发消息 |

**编辑操作**：拖动移动（自动吸附对齐，粉线提示）· 8 点缩放 · 方向键微调（Shift 加速）· Del 删除 · Ctrl+D 复制 · Ctrl+Z/Y 撤销重做 · 属性面板可「锁定」防误拖

## 4. 动画体系（三层）

1. **入场动画**（简单）：属性面板选「淡入/飞入/弹跳…」+ 时长/延迟/缓动 → 进场景自动播
2. **积木命令**（灵活）：`对 [标题] 播放 [淡入] 时长N秒` → 随时触发，按脚本顺序等待
3. **关键帧动画**（自由）：属性面板「关键帧动画…」→ 底部轨道编辑器
   - 点轨道空白打点 → 拖动改时间 → 双击删点
   - 选中点改「时间/值/缓动」；支持 X/Y/缩放/旋转/透明度
   - 积木 `对 [元素] 播放关键帧动画（循环）`

**缓动 12 条**：线性、缓入缓出（二/三次）、回拉、弹性、反弹…

**场景转场**：无 / 淡入淡出 / 推入（四方向）/ 缩放 / 擦除 / 光圈

## 5. 特效库

- **元素特效**（属性面板勾选）：光晕脉冲 / 霓虹 / 扫光 / 故障
- **场景背景特效**（场景属性）：星空 / 飘雪 / 漂浮微粒 / 极光
- **粒子爆发**（积木）：星尘 / 彩带 / 爱心 / 花瓣

## 7. 保存与分享

- **保存**：`.bdp` 单文件（内部 zip：项目数据 + 全部素材），发微信、拷 U 盘都不丢
- **自动保存**：每 2 分钟（有改动时）→ `~/.cache/jimuchang/autosave.bdp`；「更多 → 恢复自动保存」
- **导出放映包**：「更多 → 导出放映包」→ 一个 HTML 文件，浏览器双击即放（可交互），无需安装任何东西

## 8. AI 接口（可选，给折腾党）

程序运行时会在 `127.0.0.1:17800` 开一个本地接口（令牌在 `~/.config/jimuchang/api.json`）：

- **opencode**：已配置 MCP（重启后生效）→ 直接说「用积木剧场做个关于 XX 的演示」
- **Codex**：`~/.codex/config.toml` 加：
  ```toml
  [mcp_servers.jimuchang]
  command = "~/.local/bin/jimuchang-mcp"
  ```
- **任何脚本**：`curl -H "Authorization: Bearer <令牌>" http://127.0.0.1:17800/api/help`

## 9. 常见问题

| 问题 | 解决 |
|---|---|
| 积木没反应 | 检查有没有「当…」帽子积木开头；播放时会提醒孤儿积木 |
| 元素拖不动 | 检查属性面板「锁定」是否勾选 |
| 视频放不了 | 用 mp4（H.264）或 webm |
| 导出的 HTML 打开3D黑屏 | 浏览器需支持 WebGL；换个浏览器试试 |
| 声音不响 | 浏览器/程序需要你先点一下（自动播放限制）；点「播放」按钮后即有手势 |
| 3D 模型哪来 | 内置机器人；自己做的 glb/gltf 可用「导入模型」|
