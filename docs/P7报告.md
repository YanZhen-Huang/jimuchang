## 经验教训（已入记忆库）

1. python/sed 改文件后立即构建可能因 mtime 秒级精度被 make 跳过 → **改完先 touch 再 build**
2. 替换后必须 grep 验证（本轮 3 次因未验证而走弯路）
3. 测试前清理残留实例（旧实例占 API 端口导致"新代码不生效"假象）
4. `QStandardPaths` 受 `setOrganizationName` 影响路径 → 关键路径改固定拼接
5. 窗口被遮挡时 `view->grab()` 黑帧 → raise + 等待 + 黑帧警告


## 追加：运动积木（Scratch/慧编程式，2026-09-24）

参考图形化编程软件（慧编程/mBlock）的动画机制，新增「运动」分类 5 块积木：

| 积木 | 说明 |
|---|---|
| 在 N 秒内滑行到 x,y | 平滑补间移动（缓动可选），结束精确落位 |
| 沿朝向移动 N 步 | 按当前角度沿朝向移动（可配合循环画出圆弧/多边形轨迹） |
| 面向 N 度 | 设置朝向（0°=向右，顺时针为正） |
| 将 x/y/旋转/大小/透明度 增加 N | 相对变化（配合重复可做心跳、飘动、旋转加速等） |
| 下一个造型 / 切换到第 N 帧 | 帧动画手动控帧（逐帧角色动画） |

实测：12 次「移动 60 步 + 转 15°」从 (960,540) 起步，精确走到起点正下方半圆终点（直径≈460px）；滑行终点精确；旋转累加正确。


## 追加：积木库大扩充（2026-09-24，60 块）

新增 22 块积木：

| 分类 | 新积木 |
|---|---|
| 感知（新） | 读元素属性（6 种）/ 当前场景名 / 计时器 / 重置计时器 / 随机颜色 |
| 元素 | 万能属性设置 / 置于最前最后 / 说话气泡（常驻、限时、停止）/ 复制元素 / 删除元素 |
| 场景 | 重播当前场景 / 从头开始播放 / 动态背景色 |
| 逻辑 | 等待直到 / 重复直到 / 停止本脚本 |
| 媒体 | 背景音乐音量 / 停止所有声音 |
| 3D | 模型缩放 / 动画暂停继续 |

**关键实现**：说话气泡状态持久化到元素数据（场景重建后自动恢复）；`el.layer` 改为更新 DOM 层级不重建场景（避免清掉临时状态）。

**踩坑记录**：表达式块（感知类）的 IR 编译最初误加进语句编译函数，导致作为表达式求值时静默返回 0（`等待直到 计时器>1.5` 死等）；`tools/check-blocks.js` 已增强为同时校验表达式块的 IR 编译。气泡 DOM 在元素挂载前查询失败的问题通过"直接传 DOM 引用"修复。
