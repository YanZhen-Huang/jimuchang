## 1. 交付内容

### 1.1 媒体
- **音频元素**：导入音频素材、音量/循环/进场景自动播放；放映时隐藏（仅发声）
- **视频元素**：导入视频、拖拽缩放、循环/静音/自动播放；黑底渲染
- **媒体积木（4 块）**：播放音效（音量）、播放背景音乐（循环/音量/淡入）、停止背景音乐（淡出）、视频控制（播放/暂停/停止/静音）
- 音频通道管理：背景音乐通道 + 循环环境音通道 + 8 路音效池，全部支持淡入淡出

### 1.2 图表（ECharts）
- 4 种类型：柱状图 / 折线图（渐变面积） / 饼图 / 环形图
- 属性面板直接编辑分类与数值（逗号分隔）
- 暗色主题配色；`刷新图表` 积木可重新播放入场动画
- 尺寸自适应（ResizeObserver）

### 1.3 帧动画
- 两种形式：**雪碧图**（一张大图切行列）/ **序列图**（多选图片按序）
- canvas 渲染 + 全局帧循环；fps/循环可调
- 积木：帧动画 播放/暂停/停止、速度设置

### 1.4 特效库
| 类别 | 清单 | 实现 |
|---|---|---|
| 元素常驻特效 | 光晕脉冲 / 霓虹 / 扫光 / 故障 glitch | CSS 动画类 |
| 场景背景特效 | 星空 / 飘雪 / 漂浮微粒 / 极光 | canvas 粒子循环 / CSS |
| 粒子爆发 | 星尘 / 彩带 / 爱心 / 花瓣 | canvas 一次性粒子（46 粒，重力/旋转/渐隐） |
- 积木：`对 [元素] 播放粒子 [类型]`

### 1.5 编辑体验
- **撤销重做**：快照式历史（60 步、380ms 防抖合并、资源数据不重复存储）；Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z + 工具栏按钮；仅针对舞台数据，不干扰 Blockly 自带撤销
- **自动保存**：每 2 分钟静默保存到 `~/.cache/jimuchang/autosave.bdp`（脏数据时才写）
- **退出加固**：关闭时先隐藏视图 + 停止渲染再退出（规避 P0 记录的 DConfig 竞态）
- 工具栏收拢："＋更多 ▾" 下拉（形状/图标/图表/帧动画）
- 舞台留白、播放提示、特效 DOM 层级修正等

### 2.2 经验教训
- **别用 `window.X` 检查顶层 `const` 声明的模块**：`const Effects = {...}` 在全局词法环境可见（`typeof` 可用、直接引用可用），但不创建 `window` 属性。P0 用 `typeof JSZip` 检查是对的，P1/P2 的 `window.X` 检查是错的。
- **静默失败最危险**：图表/特效失效时无任何报错（被 `if (!x) return` 吞掉）；必要处保留 console.warn（如"图表初始化失败"）。
- **写测试要跑真实路径**：手写序列化 JSON 与 Blockly 真实 save 格式（如 FieldVariable 的 `{id}` 对象）不一致，会得出错误结论。
