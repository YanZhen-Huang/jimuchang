# 设置与积木补全计划（对标 TurboWarp）

> 2026-10-03 定稿 · 三期实施（S1 设置面板 → S2 积木补全 → S3 广播与高级收尾）

## 背景

用户提出：增添补全积木、加设置面板、开放更多高级选项（类似 TurboWarp 的 addons/设置思路）。

## 现状盘点

- 积木 110 块；对照 Scratch/TW 标准库缺：**数据/列表全套**、数学（三角/对数）、文本（第 N 个字符）、侦测（鼠标/碰撞/询问）、控制（停止全部）、**广播**、自定义积木带参数
- 设置散落硬编码：自动保存 120s、克隆上限 200、PPT 分辨率 1280×720、默认转场 0.6s、AI 接口仅启动参数
- 持久化现成模式：localStorage（主题/章节栏/PPT 选项）

## S1 · 设置面板

⚙ 工具栏入口 → overlay（复用 help-panel 样式）。四组：

| 组 | 项 | 默认 | 挂钩点 |
|---|---|---|---|
| 编辑器 | 自动保存间隔 关/1/2/5 分钟 | 2 分钟 | app.js autoSave 定时器 |
| 编辑器 | 对齐辅助线 开/关 | 开 | editor.js computeSnap |
| 编辑器 | 撤销步数上限 30/60/100 | 60 | history.limit |
| 编辑器 | 显示积木块数 开/关 | 关 | script-tabs 右侧计数 |
| 编辑器 | 积木音效 开/关（重启生效） | 关 | Blockly inject sounds |
| 播放与导出 | 默认转场时长 0.3/0.6/1 秒 | 0.6 | stage.goChapter |
| 播放与导出 | 播放时隐藏鼠标 开/关 | 开 | App.armCursorHide |
| 播放与导出 | PPT 高保真分辨率 720p/1080p | 720p | export-pptx.cropStage |
| 播放与导出 | PPT 图片质量 70/85/95 | 85 | cropStage toDataURL |
| 渲染性能 | 节能模式（3D/特效降 30 帧） | 关 | 帧率辅助函数 |
| 渲染性能 | 3D 模型帧率 30/60 | 60 | three-scene loop 限帧 |
| 渲染性能 | 粒子/氛围特效帧率 30/60 | 60 | effects 场景 loop 限帧 |
| 渲染性能 | 3D 阴影 开/关 | 开 | renderer.shadowMap |
| 渲染性能 | 显示帧率计数器 开/关 | 关 | 角落 rAF 计数 |
| 高级 | 显示"高级"积木分类 开/关 | 开 | toolbox 过滤 |
| 高级 | 克隆体上限 100/200/500 | 200 | executor cloneCount |
| 高级 | AI 接口（HTTP API）（重启生效） | 开 | C++ QSettings + HostBridge |

**帧率的实话**：舞台动画走 CSS/WAAPI，流畅度由屏幕刷新率决定（本机即 60）；真正可配的是 **3D/特效的 rAF 渲染帧率** 与节能模式。文档标注清楚，不吹牛。

## S2 · 积木补全

1. **数据/列表全套**（新分类）：Blockly lists 11 块 + IR 执行端新写（变量命名空间与列表独立）
2. **数学/文本/侦测/控制补全**：
   - 数学：三角/对数（IR 新）；取整/数字属性/常量（IR 已有，入工具箱）
   - 文本：第 N 个字符、包含、替换
   - 侦测：鼠标 x/y、鼠标按下、碰到 [元素/边缘]、询问并等待（播放态输入）
   - 控制：停止全部脚本
3. **小众积木包**：
   - 画笔：画线/清空/线宽/颜色（舞台 overlay canvas，跟随元素位置）
   - 音乐：弹奏音符/打击乐（Web Audio 合成，无素材）
   - 日期时间：当前时间/日期/星期（表达式）
   - 数学扩展：位运算（与/或/异或）
   - 文本扩展：大小写/修剪/分割
   - 互动：播放时拖动元素（拖拽演示）

## S3 · 广播 + 高级收尾

- 广播系统（R3 并入）：广播 [消息] / 当收到消息（元素版已就绪，补分发链路）
- 自定义积木带参数（数字/文本/布尔）
- 高级分类开关联动已有项目 + 可选积木搜索（TW 热 addon）
