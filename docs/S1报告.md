## 重大发现与修复：qrc 页面的 localStorage 不可靠

验证持久化时发现：**QtWebEngine 的 qrc:// 页面 localStorage 写入不生效/不跨会话**（原有代码全被 try-catch 吞掉——主题/章节栏/PPT 选项的"记忆"其实一直没工作过）。

**修复**：全局偏好统一改走 **C++ QSettings**（`HostBridge.setPref/getPref`，JSON 单键存储）：
- `Settings.loadFromHost(host)`：宿主就绪后读取（App.init 里 await）
- 主题 / 章节栏开合 / PPT 选项记忆 一并迁移
- 新增 `Settings.reset()` 便于测试与恢复默认
