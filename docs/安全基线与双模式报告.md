### 2.2 设计边界

“执行代码”积木仍然是设计上允许运行任意页面脚本的高级功能。本轮通过项目信任与文件桥收窄降低风险，但不把同一 WebEngine 页面里的 JavaScript 宣称为真正沙箱。后续若要允许完全不可信项目，应改为独立 Worker/iframe 且不注入宿主桥。

## 3. 章节双模式

### 3.1 数据模型

章节新增：

```json
{
  "flow": {
    "version": 1,
    "steps": [
      { "kind": "animate", "elementId": "...", "anim": "fadeIn", "duration": 0.6, "delay": 0, "easing": "easeOutCubic" },
      { "kind": "wait", "seconds": 1 },
      { "kind": "next" }
    ]
  },
  "flowMode": "auto"
}
```

- `auto`：`flow` 是章节流程源，`blocks` 是确定性投影；保存、播放、导出前会重新同步。
- `manual`：保留原有 Blockly 序列化，章节设置不会覆盖手工积木。
- 旧 v1/v2 项目如有手工积木，自动标记为 `manual`；新章节默认 `auto`。

### 3.2 生成链

```text
章节流程 → ChapterFlow.generateState() → Blockly JSON
         → IRCompiler → IR → 舞台执行器
```

当前支持：

- 颜色背景生成「把背景色设为」积木（渐变 / 图片背景无对应积木，保留预设）；
- 每个元素的显隐生成「显示 / 隐藏」积木；
- 对可见元素播放入场动画；
- 等待；
- 下一章节；
- 跳转指定章节；
- 元素显隐；
- 章节名称与背景色。

自动章节在积木模式显示只读遮罩。点“转为手工积木”后才能自由编辑；从手工模式恢复自动生成会再次确认，避免静默覆盖。

### 3.3 顺手修复

- 亮色主题主按钮文字变白导致“按钮空白”。
- 关闭对齐辅助线时拖拽读取 `null.dx` 崩溃式异常。
- 画布小于视口时缩放锚点纵向跳动。

- 章节属性面板仍读取旧 `background` 字段、并展示未生效的转场字段。
