## 1. 交付内容

### 编辑界面（三栏）
- 左：Blockly 积木工作区（深色主题、zelos 圆角渲染器、中文工具箱：事件/场景/元素/动画/逻辑/变量/函数）
- 右：场景标签页（全局 + 各场景 + 新建/删除）+ 舞台预览（16:9 自适应缩放）+ 属性面板
- 工具栏：新建/打开/保存、＋文字/图片/形状/图标、示例、▶ 播放

### 场景与元素
- 场景：背景色/渐变、转场（淡入淡出/推移/缩放）、场景增删改名
- 元素：文字、图片（导入对话框）、形状（矩形/圆/椭圆/三角/箭头/直线）、emoji 图标
- 编辑操作：点击选中（8 点缩放手柄）、拖拽移动、方向键微调（Shift 加速）、双击文字直接改、删除/复制/层级调整
- 属性面板：位置尺寸/旋转/透明度 + 各类型专属属性（字号/颜色/对齐、填充/描边/圆角、图片填充方式等）+ 入场动画设置 + 预览动画

### 动画
- 20 种动画：淡入淡出、四方向飞入飞出、放大缩小、旋转、弹跳、翻转、打字机、脉冲/抖动/摇摆/呼吸/光晕
- 12 条预设缓动（cubic-bezier + linear() 采样精确实现）
- 元素入场动画：属性设置 + 播放时自动触发 + 编辑时手动预览
- 场景转场：6 种 + 时长可调

### 积木与执行引擎
- 24 块自定义积木（4 事件帽子 + 3 场景 + 6 元素 + 2 动画 + 逻辑/变量/函数分类）
- 积木编译为 IR 指令（不生成 JS），异步解释器执行：wait/scene/el/anim/var/if/repeat 全支持
- 事件驱动：当演示开始 / 当进入场景 / 当按下键 / 当点击元素
- 场景脚本随场景切换自动中止（时代令牌机制）

### 播放模式
- F5 或 ▶ 进入全屏放映；空格推进（无脚本接管时切下一场景）、←→ 场景、Esc 退出
- 全屏 ↔ 编辑无缝切换（WebChannel 调原生全屏）

### 项目文件
- `.bdp` 单文件（JSZip：project.json + resources/），资源全部内嵌
- 保存/打开/最近文件路径；未保存标记（标题旁蓝点）；打开/新建前脏数据确认

### 示例
- 内置 3 场景示例演示（封面渐变 + 特性图标 + 打字机结尾，含完整积木脚本与转场）

## 4. 使用方式

```bash
# 已安装
jimuchang                    # 或桌面/菜单点"积木剧场"
jimuchang 项目.bdp            # 直接打开项目

# 开发
cd ~/jimuchang && cmake --build build -j && ./build/jimuchang
```

快捷键：Ctrl+S 保存 / Ctrl+O 打开 / Ctrl+N 新建 / F5 播放 / Esc 退出播放或取消选择 / Del 删除 / 方向键微调 / Ctrl+D 复制元素
