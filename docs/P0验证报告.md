## 2. 关键发现（影响后续开发）

### 2.1 fetch 不支持 qrc:// 协议（重要）
- 现象：`Fetch API cannot load qrc:///... URL scheme "qrc" is not supported`
- 影响：凡是用 fetch/XHR 加载资源的库都会失败——GLTFLoader（3D 模型）、ECharts 地图 JSON、Blockly 音效（已用 `sounds:false` 规避）
- 可用清单（qrc 下）：`<script src>`、`<link>`、`<img>`、`<video>`、`<audio>`、ESM `import()` 均正常
- 对策（P1 二选一，倾向 A）：
  - **A. 注册自定义 URL scheme**（`app://` + QWebEngineUrlSchemeHandler 读 qrc，让 fetch 正常工作）——一劳永逸
  - B. 需要 fetch 处改 base64 内联 / QWebChannel 读文件

### 2.2 截图方案提前锁定
- `QWebEngineView::grab()` 实测可用（含全屏状态），**AI 接口截图采用方案一**，无需 devtools/printToPdf。

### 2.3 其他
- 无需任何 `QTWEBENGINE_CHROMIUM_FLAGS` 特殊参数（沙盒/GPU 正常）。
- 低概率退出段错误：`DConfigGlobalTh`（Deepin DConfig 线程）在"全屏切换+退出"链路上的竞态，复现 0/2 次；P1 做退出加固（hide → 停加载 → deleteLater 顺序）。
- QtWebEngine 导致 `setHighDpiScaleFactorRoundingPolicy` 警告（Qt 内部在 QApplication 后调用），无害。
- Blockly 默认白色画布，P1 需注册深色主题（配色见技术文档 9.1）。
