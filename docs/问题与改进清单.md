## 详述

### ① 「背景特效」选了没反应（真 bug）
- **现象**：属性面板（未选中元素时显示的"舞台与章节"面板）里选星空 / 飘雪 / 微粒 / 极光，舞台无任何变化。
- **验证**：`web/js/editor.js:333` 面板读写的都是当前章节 `sc.fx`；而渲染只读舞台级 `Project.data.stage.fx`（`web/js/stage.js:156`，注释写着"原场景特效，v2 挂舞台"）——数据源错位，面板写进了一个没人读的地方。
- **修法**（约 10 行）：面板 `fx.type` 的读 / 写都改为操作 `Project.data.stage.fx`（editor.js renderScene 下拉取值 + 属性变更处理里特判 `path === 'fx.type'` 时写入 stage）。渲染侧已就绪，无需改动。
- **备选**（大改，不做）：让"每章不同特效"生效（章节 fx），需改 goChapter / renderAll 时机。
- **附**：该面板标题「舞台与章节」语义混乱（面板里全是章节的设置，舞台本身没有任何设置项）——随 ④ 一起改。

### ⑤a 双指缩放乱入（触摸板）
- **现象**：触摸板双指捏合把整个编辑器 UI 当网页缩放（`touch-action: none` 只能拦触摸屏，拦不住触摸板的 Ctrl+Wheel 路径）。
- **修法**（短期）：全局 wheel 监听里 `if (e.ctrlKey) e.preventDefault()`，禁止页面缩放。

### ⑧ 新用户入口缺失（最根本的一条）
- **验证**：全代码无"另存为"；主页（home-overlay）仅在「＋更多 ▾」里且启动不弹；无模板库；无新手引导；3D / AI / 图表 / 关键帧等专业功能全藏在工具箱分类里。
- **批语原话**："软件的出口（导出）想得周全，但入口完全没管——用户得先接受一套自创概念，却没给梯子。"
- **修法（建议顺序）**：
  1. 文件区补「另存为」/「保存副本」
  2. 启动首屏（新建 / 示例 / 模板 / 最近文件）——把 home-overlay 提到启动时展示
  3. 内置 3~5 个"打开就能改"的模板（自我介绍 / 课堂演示 / 节日贺卡 …）
  4. 「能做什么」导览页：专业功能一屏展示

### ② 工具栏逻辑混乱
- **现象**：文件操作、插入元素、主题 / 设置 / 帮助 / AI、示例、导出、播放——六类东西平铺一排无分组，找东西全靠背位置。
- **位置**：`web/index.html:15-54`（#toolbar）
- **修法**：按任务分组（文件｜插入｜演示｜全局），主题 / 帮助 / 设置收入统一菜单；播放 / 导出保持显著。

### ③ 两个元素选择区（功能重复）
- **位置**：积木区顶部「全局｜选择元素…▾」（`app.js renderScriptTabs`）+ 舞台下方元素条（`app.js renderElementBar`）。点击行为实质相同（都是"选中该元素 + 切到它的脚本"）。
- **修法**：合并为一处入口。建议保留舞台下元素条（含右键菜单）为唯一元素入口；积木区脚本区改为跟随"当前选中元素"自动切换（去掉下拉）。

### ④ 整体 IA 偏"展示品"
- **批语**："布局设计整体感觉不是专业高效办公的，是一个艺术品，展示品。"
- **方向**：目标 = 生产力工具（对标 WPS）。需重排信息架构：工具栏分组、面板可收纳、提高信息密度、统一交互预期。与 ② ③ ⑧ 一并做。

### ⑦ 无响应式 / 大屏 / DPI 适配
- **验证**：`app.css` 中 `@media` 数量 = 0；DPI 仅 `PassThrough` 取整策略，无密度适配。
- **现象**：大屏 / 高分屏下 UI 等比放大（"雷霆大按钮"）、布局不重排、大屏空间浪费。
- **修法**：加 @media 断点（≥2K 收紧密度、放大工作区）、工具栏与面板弹性调整；（可选）设置内提供"界面缩放"。

### ⑥ 内核行为治理欠账
- **事实**：QtWebEngine 内核（选型合理：Blockly / Three.js / ECharts / 放映包全绑 Web 生态），但"浏览器默认行为"只堵了一部分：
  - GPU：默认有合成加速，但无显式策略（无显卡偏好、无软渲染回退）；本机 NVIDIA+Intel 双显卡是 Chromium 花屏高发区
  - 快捷键泄漏：Ctrl+P 等需逐一检查接管
  - 其他：右键菜单、拖拽入文件、文本选择、自动填充
- **修法**：立"内核行为治理"专项——Chromium flags / 环境变量策略 + 快捷键全表接管 + GPU 回退开关（做成设置项）。

### ⑤b 无画布缩放 ✅ 已完成（2026-10-05）
- **Ctrl+滚轮 / 双指捏合**（指针为锚点）与 **Ctrl+= / Ctrl+-** 缩放画布；**Ctrl+0** 适应窗口、**Ctrl+1** 回到 100%（与 4.1.4 快捷键表一致）
- **空格拖动 / 中键拖动**平移；画布未溢出时自动居中（边界 clamp，不会拖出视野）
- 右下角缩放控件（− % ＋ 适应，半透明低调）；普通滚轮在舞台上也是平移（方便浏览放大后的画布）
- 播放模式强制适应窗口、退出自动恢复用户视图；PPT 高保真导出前自动重置视图（避免裁偏）
- 自动化：`--test-canvaszoom`（9 项断言）+ `--test-playview`（播放视图隔离）+ `tools/test-regress.sh` 批跑
