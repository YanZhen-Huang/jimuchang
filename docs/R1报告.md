## 本期修复的 bug（回归中发现）

1. **迁移显隐误判**：v1→v2 时该元素须"在 v1 场景中且未手动隐藏"才亮——`inScene.has(id) && visible !== false`
2. **App.init 漏首次渲染**：补 `Stage.renderAll()`
3. **PPT 导出错用运行时 visible**：非当前章节元素的 `visible=false`（运行时状态）被当持久隐藏 → 第 2/3 页全空、动画只注入 1 页。修复：显隐只看章节预设，无预设才看元素状态
4. **PPT 高保真残留变量**：`scene is not defined`（buildFidelity 里 addNotes 仍用旧变量名）
5. **放映包空白**：`goChapter` 假设舞台已渲染（编辑器有、播放器没有）→ 加 `_renderedOnce` 首次渲染保险
