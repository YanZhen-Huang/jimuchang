## v0.4.2 · 素材区 + 章节双模式 + AI/MCP 安全增强

这次更新把创作入口、素材管理和 AI 驱动连成了一条完整链路。

### 素材区

- 工具栏新增「素材」，支持图片、音频、视频、3D 模型和 HTML 网页；
- 批量导入、搜索、类型筛选、缩略图、改名；
- 拖到舞台或双击素材直接创建元素；
- 元素、背景、音乐仍在引用时禁止删除；
- 素材继续随 `.bdp` 单文件保存。

### 章节双模式

- 顶部切换「积木 / 章节」两种创作模式；
- 章节背景色、元素显隐、动画、等待和跳转全部自动生成 Blockly 积木；
- 自动章节默认锁定，转为手工积木后才能自由编辑；
- 手工积木不会被章节配置静默覆盖；
- 兼容旧 v1 / v2 项目。

### AI 与 MCP

- AI 会读取当前素材清单，直接复用素材区中的图片、音频、视频、3D 和网页；
- 新增素材引用指令，缺少素材时跳过并提示，不编造路径；
- MCP 扩展到 35 个工具；
- 新增章节流程、素材查询、重命名、删除、批量上传和从素材创建元素等工具；
- API 返回失败时，MCP 现在会返回真实工具错误，不再伪装成成功。

### 安全与质量

- 本地 HTTP API 默认关闭，需要时在设置中开启；
- 配置目录权限收紧为 `700`，`api.json` 与 AI Key 配置为 `600`；
- AI Key 不再混入普通设置 JSON；
- 文件桥增加路径和扩展名白名单；
- 打开含执行代码或嵌入网页的陌生项目时要求确认；
- 依赖漏洞清零。

### 验证

- 174 块积木自检通过；
- 章节流程转换自检 13/13；
- 完整 GUI 回归 21/21；
- MCP 工具发现 35 项，真实素材/章节调用链路通过；
- `npm audit`：0 个已知漏洞。

本 Release 附带 28 秒更新视频 `jimuchang-update.mp4`，以及 GitHub 仓库中的 Remotion 源码。

### 升级提示

- 本地 AI 接口为安全默认关闭，升级后如需 MCP/AI 外部驱动，请到「设置 → 高级」开启并重启；
- 旧项目打开时会自动兼容；含手工积木的章节不会被自动流程覆盖。
