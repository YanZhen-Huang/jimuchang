## P3 关键帧动画

- **轨道编辑器**（底部抽屉面板）：5 条属性轨道（X位移/Y位移/缩放/旋转/透明度）
  - 点轨道空白打点（值自动取当前时刻插值）、拖动点改时间、双击/右键删点
  - 选中点后顶部编辑区改 时间/值/缓动；时长与循环可调；▶ 试播；清空
  - 面板编辑自动进撤销历史
- **采样引擎**：线性插值 + 12 条预设缓动（每段可选）；rAF 驱动；`播放关键帧动画（循环）`积木
- 验证：通道打点 7 个、采样精确（x 中点 710.0 = 460+500×0.5）、试播与面板渲染通过

## P4-1 3D 子系统

- 自动居中 + 自适应相机距离 + 多实例并行渲染
- 验证：机器人渲染 + Wave 骨骼动画 + 镜头 + 冷色灯光 + 星空，截图确认

## P4-2 自制程序

- 验证：代码块改写标题成功（"代码块生效！"）、函数"出场三连"执行、小程序渲染

## P5 AI 接口

### 本地 HTTP API（127.0.0.1:17800）
- 实现：C++ QHttpServer + QTcpServer；**回调模式**（JS 处理完经 QWebChannel 回传，绕开 runJavaScript 不解析 Promise 的限制）；15 秒看门狗
- 鉴权：Bearer 令牌（自动生成并写入 `~/.config/jimuchang/api.json`）
- 端点：status / help / project(GET/PUT/new/save/open) / scenes(CRUD) / elements(CRUD/animate/keyframes) / blocks(场景与全局) / resources / play / play:stop / **screenshot（C++ 直接抓屏返回 base64 PNG）** / export
- 验证：401 鉴权、status、API 建元素、API 播放/停、场景改名、截图 —— 全部实测通过

### MCP 服务器
- `~/.local/bin/jimuchang-mcp`（Node，stdio；SDK 1.30 CJS 子路径引入）
- **23 个工具**：jc_status/help/get_project/put_project/new/open/save、场景与元素 CRUD、animate、set_keyframes、set_blocks、upload_resource、play/stop、**jc_screenshot**、jc_export
- 已注册进 opencode（`~/.config/opencode/opencode.jsonc`，备份 `.bak-jimuchang`）；**重启 opencode 生效**
- 验证：MCP 握手 initialize + tools/list（23 工具）通过

## P6 导出放映包

- 产物：**单文件 HTML**（`<项目名>-放映机.html`），双击用浏览器打开即可放映，可发微信
- 原理：导出时把演示内容**预编译为 IR**（播放器不含 Blockly）+ 引擎源码从 qrc 读取拼接 + 资源以 data URL 内联
- 按需内联：项目含 3D 元素时才内联 three（用 Blob URL 链解决 ESM 相对依赖）；内置机器人模型也内联
- file:// 兼容：无 fetch 依赖、媒体全内联
- 交互照旧：点击/按键/空格推进/双击全屏
- 验证：导出 3.7MB 单文件（含 three+模型）→ **用 WebEngine 以 file:// 打开** → 机器人/动画/星空/文字全渲染，无 JS 错误

| 播放器调试 | 无开发者工具（浏览器打开时可用 F12） |

## 使用说明（AI 接口）

```
1. 启动积木剧场（API 自动开启，配置在 ~/.config/jimuchang/api.json）
2. opencode：已注册 MCP（重启 opencode 生效）
3. Codex：可手动加（~/.codex/config.toml）：
   [mcp_servers.jimuchang]
   command = "~/.local/bin/jimuchang-mcp"
4. 问我"用积木剧场做个 XX 演示"，我会：建项目→放元素→写脚本→截图自检→导出放映包
```
