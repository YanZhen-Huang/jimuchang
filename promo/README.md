# 积木剧场 · 宣传片（代码化渲染）

不是用剪辑软件剪的，而是**一个 HTML 时间轴 + 逐帧渲染**：

```
promo.html      1920×1080 动画（window.setTime(t) 确定性渲染任意时刻）
render.js       Playwright(系统 Edge headless) 逐帧 setTime → JPEG → ffmpeg 合成 MP4
snap.js         静帧预览（只截指定时间点，秒级出图，审美迭代用）
```

## 设计方向（v3 · 暖米白画廊调 · 20 秒）

- **基调**：暖米白（`#F4F2ED`，非纯白，有纸质感）+ 炭黑文字（`#1C1F26`）+ 深金点缀（`#B8862B`）；积木三色（红 `#D6482F` / 黄 `#E0A121` / 蓝 `#3B6BE0`）只出现在积木块与产品卡上
- **背景**：积木底板抽象——72px 浅格网 + 每格微凸点 + 暖金光斑 + 边缘轻微加深
- **字体**：标题用**思源等宽**（工程气质），正文 Noto Sans CJK SC
- **签名元素**：2×2 凸点标记（品牌角标 / 场景金色 eyebrow：BUILD / CREATE / SHARE）+ 开场阳光扫光 + 结尾金线扫过
- **节奏**：20 秒（v2 的 30 秒压缩 1/3），每个入场 0.35–0.6s；每场景一个叙事动作，结尾彩色纸屑是全片唯一"大特效"
- 无节日元素（v2 的灯笼已移除）

## 重新渲染

```bash
cd promo
node render.js 20 ~/Desktop/积木剧场-宣传片.mp4   # 20 = 时长（秒）
node snap.js 1.3 6 9.5 14.5 20.5 27               # 静帧预览 → /tmp/snap-*.png
```

- 依赖：系统 Edge（`microsoft-edge`）、Node、ffmpeg（系统自带）、npx 缓存里的 playwright
- 渲染 900 帧约 40 秒（22 fps），输出 1080p / 30fps / ~3.4MB
- 改动 `promo.html` 里任意元素/时间轴 → 重渲即可，无掉帧、无时序抖动（帧 = 纯函数 f(t)）

## 时间轴（20s）

| 时间 | 场景 | 内容 |
|---|---|---|
| 0–2.8s | 开场 | 「积木剧场」标题 + 副标题 + 阳光扫光 |
| 2.6–6.9s | 拖积木 | 三块积木（事件/动画/声音）飞入拼接 → 播放 |
| 6.7–11.2s | 能力 | 3D 机器人与图表截图卡片层叠 + 特性 pill |
| 11–15.8s | 导出 | 四张导出卡（HTML / MP4 / PPT / exe）依次点亮 |
| 15.7–20s | 结尾 | 金线转场 + 标题 + GitHub + 彩色纸屑 |
